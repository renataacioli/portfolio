Process

Finished logos,
new movement.

01

Respect the mark

Each logo came with careful design decisions behind it. The animation has to show those decisions without breaking them, so I start by studying how the mark is built: geometry, weight and attitude.

02

Find each voice

Each brand moves in its own way. Cine Ninja got a nervous glitch, Ella's lettering writes itself like a signature and the Clube Ativista badge snaps together with activist energy. Its three versions share one system with different tempos.

03

Build it to loop

These logos appear in feeds and video openers, so each animation ends in a clean loop, reads in seconds and is exported ready to use.

Outcome

Still on air.

They're still in use, opening live events, heading YouTube videos and shorts, and signing the brands' videos.

Case · Mídia Ninja video kit

Mídia Ninja then asked for a full animated video kit to speed up the editing of its news pieces: caption presets, transitions, visual effects, animated backgrounds, logo animation and opening and closing vignettes, built with an After Effects → Premiere integration.

I delivered it as an editable Premiere timeline, so editors only drop in the raw footage and cut.
